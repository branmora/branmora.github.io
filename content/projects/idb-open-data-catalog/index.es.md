En el Catálogo de Datos Abiertos del BID, el Banco Interamericano de Desarrollo comparte datos que puedes reutilizar: conjuntos de datos, datos de investigación vinculados a sus publicaciones, indicadores calculados y portales de datos temáticos, además de una API para los datos y sus metadatos. El catálogo renovado se lanzó sobre CKAN, el software de código abierto para catálogos de datos.

El paso a CKAN tomó 14 meses, en cinco fases: diseño, preparación, implementación, pruebas y despliegue. Con Emelin Batres escribí sobre el nuevo catálogo en Abierto al Público, el blog del BID, y presentamos el proceso en CKAN Monthly Live el 2025-09-17 (en inglés).
